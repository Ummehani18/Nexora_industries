# NEXORA Static Website

A static, responsive website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Use the Live Server extension and open `index.html`.
4. You can also open `index.html` directly, but Live Server is recommended for testing.

## Before publishing
Open `config.js` and update:
- `whatsappNumber`: digits only, include UAE country code (example format: 9715XXXXXXXX)
- `phoneDisplay` and `phoneLink`
- `email`
- default WhatsApp message

Also review the office address, working hours, service descriptions, course durations, map pin and every accreditation claim. The location/map and contact details in this template are based on the information supplied in the project conversation and must be confirmed by the client.

## Features
- Splash screen
- Responsive navigation with active section state
- English/Arabic content toggle with RTL layout
- Eight service cards and one consolidated WhatsApp CTA
- Accreditation and compliance section
- Training pillars plus six timeline-style courses and durations
- Click-to-call, WhatsApp, email, Google Maps embed and directions
- SEO title, description, Open Graph tags, semantic sections, lazy-loaded lower images and reduced-motion support

## Hosting
This is a static site and can be deployed to a static hosting platform such as Cloudflare Pages or GitHub Pages. The WhatsApp links work without a backend. The map requires an internet connection. Images are loaded from Unsplash URLs; download and host approved image files locally if the client prefers fully local assets or wants to avoid external image dependencies.

## Important content note
The page includes an accreditation/compliance section because it was requested, but its copy intentionally instructs the site owner to verify current accreditation certificates and scope. Do not publish accreditation claims, logos or standards as established facts unless the company confirms them with current documentation.


## Visual direction update
The UI uses a technical editorial direction: blueprint grid, deep ink/navy surfaces, signal-lime accents, sharp service-index grid, asymmetric industrial imagery, and a custom multi-column footer that differs from the reference screenshot. All original service/training/contact content remains in place.
